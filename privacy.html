Privacy Policy - Laptop1 Channels

Last updated: 20 October 2026

What the app accesses

With the channel owner's permission, the app uses two read-only Google permissions: "View your YouTube account" (youtube.readonly) and "View YouTube Analytics reports" (yt-analytics.readonly). It reads the owner's own channel statistics only.

How the data is used

The data is used only to make reports for the channel owner (for example: which videos people watch longest, where viewers leave). Nothing is sold, shared with third parties, or used for advertising.

Where the data is stored

Reports and the access token are stored only on the owner's own computer. No data is stored on any server.

How to remove access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the local report files removes all stored data.

Google API Services User Data Policy

Laptop1 Channels' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
